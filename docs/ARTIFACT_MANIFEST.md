# Artifact Manifest

This repository starts as a scaffold. Large generated artifacts should not be committed unless they are small publication tables or figures.

## Commit

- Manuscript source and compiled PDF when ready
- Small CSV tables used in the paper
- Publication figures
- Configuration files
- Reproducibility notes

## Do Not Commit

- API keys
- `.env` files
- virtual environments
- model checkpoints
- raw rollout JSONL files
- large training artifacts
- temporary LaTeX build products
